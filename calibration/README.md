# Calibration

Method:

1. Three senior PMs each score the same set of recorded answers using `rubric/rubric.md`.
2. The grader prompt scores the same answers (median of 3 runs).
3. We measure per-criterion agreement between the PMs and between the PMs and the grader.
4. Results are published in this folder.
5. The exercise is re-run whenever the model changes.
